================================================================================
                          API ENDPOINT DETAILS
================================================================================

Endpoint: https://api.aipipe.io/v1/messages

HTTP Method: POST

Headers:
  Authorization: Bearer {AIPIPE_TOKEN}
  Content-Type: application/json

Request Body:
  {
    "model": "claude-opus-4-1",
    "max_tokens": 2048,
    "system": "Your system prompt",
    "messages": [
      {
        "role": "user",
        "content": "User question"
      }
    ]
  }

Response:
  {
    "content": [
      {
        "type": "text",
        "text": "{\"answer\": \"...\", \"log_url\": \"...\"}"
      }
    ],
    "stop_reason": "end_turn",
    "usage": {
      "input_tokens": 150,
      "output_tokens": 50
    }
  }

================================================================================
                        CODE COMPARISON
================================================================================

OLD CODE (Direct Anthropic):
──────────────────────────────

from anthropic import Anthropic

client = Anthropic(api_key=api_key)
response = client.messages.create(
    model="claude-opus-4-1",
    max_tokens=2048,
    system=system_prompt,
    messages=[{"role": "user", "content": question}]
)
text = response.content[0].text

NEW CODE (aipipe):
──────────────────────────────

import requests

headers = {
    "Authorization": f"Bearer {aipipe_token}",
    "Content-Type": "application/json"
}
payload = {
    "model": "claude-opus-4-1",
    "max_tokens": 2048,
    "system": system_prompt,
    "messages": [{"role": "user", "content": question}]
}
response = requests.post(
    "https://api.aipipe.io/v1/messages",
    headers=headers,
    json=payload
)
text = response.json()["content"][0]["text"]

================================================================================
                          TROUBLESHOOTING
================================================================================

Q: "AIPIPE_TOKEN not set"
A: Run python setup.py to create .env file with your token

Q: "API error: 401"
A: Check your aipipe token is correct and not expired

Q: "API error: 429"
A: Rate limited - wait a moment and try again

Q: "Empty response from API"
A: aipipe returned no content - check your token permissions

Q: "Connection timeout"
A: Network issue - check internet connectivity

Q: "Invalid JSON response"
A: Run python test_bot.py to debug
